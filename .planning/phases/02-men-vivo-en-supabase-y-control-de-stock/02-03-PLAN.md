## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → `/api/admin/menu` | Frontera de privilegio: quien pase esta ruta puede cambiar el precio que se cobra. Cubierta por el Basic Auth de `proxy.ts` |
| navegador de Jaime → `PATCH /api/admin/menu` | Autenticado pero no confiable en el contenido: un typo es tan dañino como un ataque |
| ruta → Postgres (service_role) | Escritura con poderes totales sobre `menu_items` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-11 | Elevation of Privilege | `/api/admin/menu` accesible sin credenciales | mitigate | La ruta vive bajo `app/api/admin/`, cubierta por el matcher `/api/admin/:path*` de `proxy.ts`. Gate: `proxy.ts` no se modifica y el path del archivo no cambia |
| T-02-12 | Tampering | Precio a S/0 o absurdo por typo soles-vs-céntimos; un producto a 0 pasaría el `MIN_CENTS` de `/api/charge` si el resto del carrito compensa, y regala comida | mitigate | Rango duro `[300, 10000]` céntimos validado antes del UPDATE, con 400 explícito y test que verifica que `updateMenuItem` no se llamó |
| T-02-13 | Tampering | `agotado` enviado como string `"false"` (truthy) marca un producto como agotado sin querer, o al revés | mitigate | `typeof agotado === "boolean"` estricto; cualquier otro tipo es 400 |
| T-02-14 | Tampering | Body con claves extra (`name`, `category`, `image`) modificando la carta más allá de precio/stock | mitigate | El patch se construye por lista blanca de dos claves; nunca se pasa el body al UPDATE |
| T-02-15 | Information Disclosure | El listado del panel expone columnas internas | accept | `getMenuItemsCached` ya hace `select()` con lista explícita de columnas (plan 02-01); esta ruta es además admin-only |
| T-02-16 | Repudiation | No queda registro de quién cambió un precio ni cuándo | accept | Un solo admin (Jaime) con Basic Auth compartido; auditoría de cambios de precio no está en el alcance de v1 y no hay segundo usuario del que distinguirlo |
